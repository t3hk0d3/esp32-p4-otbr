# Logging Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every log line of the P4 firmware (ESP-IDF, OpenThread, ziggurat) reaches four channels (UART, USB-JTAG,
syslog over UDP, live WebSocket viewers), each filtered by its own level and by a per-component level, set from a
single Device → Logs page.

**Architecture:** A new `logging` component wraps ESP-IDF's log entry points at link time (`esp_log`, `esp_log_va`),
so it sees every line with its level and tag. The UART keeps ESP-IDF's own synchronous path. Lines wanted by any other
channel are formatted into a small transit ring, and a drain task fans them out to USB-JTAG, syslog and per-viewer
queues that `device_api` sends as WebSocket frames. ESP-IDF's per-tag levels act as the generation gate, so nothing is
formatted that no channel accepts. OpenThread (`--wrap=otPlatLog`) and ziggurat (patched tracing hook) feed the same
path, and their own levels follow their component levels.

**Tech Stack:** ESP-IDF v6.1 (log v1, esp_http_server WebSocket, usb_serial_jtag driver, lwIP sockets, NVS),
FreeRTOS, OpenThread, ziggurat (Rust staticlib built by `p4/components/zigbee/tools/build_staticlib.sh`), plain
JS pages tested under node, pytest-embedded.

**Spec:** `docs/superpowers/specs/2026-11-10-logging-design.md` (read it with this plan).

**Styleguide:** `STYLEGUIDE.md` (enforced by `make lint`). Everything below follows it: public symbols `logging_`,
one `static const char *TAG = "logging"` per file, `esp_err_t` returns with `ESP_RETURN_ON_ERROR`, host tests in
`p4/components/logging/test_host/` named `TEST_CASE("<scenario>: <effect>", "[logging]")`, target tests in
`p4/pytest/test_logging.py`, page logic tests in `tools/tests/test_logs_page.py`, vendored changes listed in
`p4/components/PATCHES.md`, docs one topic per file in `docs/`.

## Global Constraints

- Channels: UART, USB-JTAG, syslog (UDP), live WebSocket. A line goes out on a channel only if it passes its
  component's level AND the channel's level.
- Levels, in API and UI: `off`, `error`, `warning`, `info`, `debug`, `verbose` (= `esp_log_level_t` 0..5).
- Defaults (fresh NVS): UART `info`, USB-JTAG `info`, syslog `off` with target `""`, component default (`*`) `info`,
  no overrides. A fresh board's UART output equals today's.
- Syslog target: one field `host[:port]`, port 514 when omitted; `host` may be IPv4, `[IPv6]`, or a hostname.
- Syslog: RFC 5424 over UDP, one line per datagram, facility `local0` (16), severity error 3 / warning 4 / info 6 /
  debug and verbose 7, HOSTNAME = `netnames_hostname()`, APP-NAME = tag, TIMESTAMP from `time()` (UTC, ms, `Z`)
  only when the clock is valid, else `-`; MSG starts with the uptime in ms.
- Live view: only lines after connect; per-viewer level (default `info`); no on/off switch; no client = no work;
  same per-interface policy as `/device/console/ws` (403 where the device API is not served).
- No on-board log history: the transit ring is a buffer, never read back by an API.
- Never block a producer: a full ring or a full viewer queue drops lines and counts them. No logging from the send
  path back into the log (feedback loop).
- Component overrides capped at 32; known tags remembered since boot, capped at 64; tag length < 24.
- UART output stays synchronous (lines before a crash still appear) and complete at its level.
- `CONFIG_LOG_TIMESTAMP_SOURCE` unchanged; UART/JTAG/live lines carry uptime ms.
- Code on the OpenThread or esp_timer task never calls lwIP (STYLEGUIDE "Tasks and locks").
- ziggurat's log hook ships as a patch applied by `build_staticlib.sh` to its work copy; the submodule stays on
  f917f98 and clean. The upstream issue/PR texts are shown to the user before posting.
- No flashing inside tasks (user rule): one batched on-board pass (Task 12) after review and fixes, with the user's
  go. Before any on-board action re-read `/device/status` `app.version` in a separate step.
- Commands are run as `<command> 2>&1 | tee <scratchpad>/<name>.log` (user rule).

## Review Focus

1. **OpenThread's three-part lines** (prefix, body, `\n` in separate `esp_log_write` calls) arrive on every channel as
   one line. Pinned by Task 5's `otPlatLog` wrap test and the target test `test_ot_line_is_whole`.
2. **A dead or unreachable syslog target** (host down, ICMP unreachable, unresolvable name) must not stall or flood:
   lines are dropped and counted, state shows `unresolved`, nothing is logged about it. Pinned in Task 4
   (`syslog send error: counted, no log line`) and target test `test_syslog_unresolvable_target`.
3. **A viewer that stops reading** (browser tab in background, `websocat` paused) must not grow memory or slow others.
   Pinned in Task 7 (`full viewer queue: drops for that viewer only`) and target test `test_slow_viewer_drops`.
4. **Settings edits from two places** (web page and UART `log` command) at once must not corrupt the stored settings.
   Pinned in Task 3 (`concurrent apply: last writer wins whole`).
5. **Long lines** (hex dumps, OpenThread's dataset dumps, > 1 KB) are truncated with a marker, never split across
   frames or datagrams. Pinned in Task 2 (`line longer than LOGGING_LINE_MAX: truncated with marker`).

## Public contract (`p4/components/logging/include/logging.h`)

Data shapes every task relies on:

- `typedef enum { LOGGING_CH_UART, LOGGING_CH_JTAG, LOGGING_CH_SYSLOG, LOGGING_CH_COUNT } logging_channel_t;`
- Constants: `LOGGING_TAG_MAX 24` (incl. NUL), `LOGGING_COMPONENTS_MAX 32`, `LOGGING_KNOWN_TAGS_MAX 64`,
  `LOGGING_TARGET_MAX 128`, `LOGGING_LINE_MAX 512` (body bytes, incl. truncation marker `…[cut]`),
  `LOGGING_VIEWERS_MAX 4`, `LOGGING_SYSLOG_PORT 514`.
- `logging_component_t { char tag[LOGGING_TAG_MAX]; esp_log_level_t level; }`
- `logging_settings_t { esp_log_level_t channel[LOGGING_CH_COUNT]; char syslog_target[LOGGING_TARGET_MAX];
  esp_log_level_t default_level; uint8_t n_components; logging_component_t components[LOGGING_COMPONENTS_MAX]; }`
- `typedef enum { LOGGING_SYSLOG_OFF, LOGGING_SYSLOG_RESOLVING, LOGGING_SYSLOG_SENDING, LOGGING_SYSLOG_UNRESOLVED }
  logging_syslog_state_t;`
- `logging_status_t { bool jtag_host; logging_syslog_state_t syslog; uint8_t viewers;
  uint32_t sent[LOGGING_CH_COUNT]; uint32_t dropped[LOGGING_CH_COUNT]; uint32_t live_dropped; }`
- `typedef struct { uint32_t uptime_ms; esp_log_level_t level; char tag[LOGGING_TAG_MAX]; uint16_t len;
  const char *text; } logging_line_t;` (text not NUL-terminated; valid until the next read on that viewer)

### Task 3: Transit ring and settings apply/store

**Files:**
- Create: `p4/components/logging/logging_ring.c`, `logging_ring.h`, `logging_settings.c`, `logging_priv.h` (ops
  seam: NVS get/set blob, `esp_log_level_set`, clock), `test_host/main/test_ring.c`, `test_host/main/test_settings.c`

**Interfaces:**
- Produces (ring): `void logging_ring_init(logging_ring_t *, uint8_t *buf, size_t size)`, `bool
  logging_ring_reserve(logging_ring_t *, size_t max_text, logging_ring_slot_t *slot)`, `void
  logging_ring_commit(logging_ring_t *, logging_ring_slot_t *slot, const logging_line_t *meta, size_t text_used)`,
  `bool logging_ring_pop(logging_ring_t *, logging_line_t *out, char *text, size_t cap)`, `uint32_t
  logging_ring_dropped(const logging_ring_t *)`. Size: 16 KB, internal RAM (`MALLOC_CAP_INTERNAL`), allocated in
  `logging_start`.
- Produces (settings, public): `esp_err_t logging_init(void)`, `esp_err_t logging_get_settings(logging_settings_t
  *)`, `esp_err_t logging_apply(const logging_settings_t *, const char **bad_field)`, `esp_err_t
  logging_level_listener_add(const char *tag, void (*cb)(esp_log_level_t effective))` (up to 4 listeners; called on
  the applying task, after the lock is released), internal `void logging_viewers_max_changed(esp_log_level_t)`.
- NVS: namespace `logging`, key `settings`, one blob = version byte (1) + `logging_settings_t`.

Ring algorithm (multi-producer reserve, single consumer; the tricky part):

```
reserve(n):  under spinlock (portMUX, held for index math only):
                 need = header + n rounded up; wrap to start if the tail gap is too small (mark a skip header)
                 if free < need: dropped++; return false
                 slot = head; head += need; mark slot header "reserved"
             format into slot outside the lock
commit(slot, used): write header (meta, used); then mark "committed" with a release store
pop():       at tail: if header is "skip": tail = 0; if "reserved": return nothing (producer still writing)
```

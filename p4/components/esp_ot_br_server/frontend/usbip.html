How to attach

If the device resets or is unplugged, the computer sees it unplugged: attach again with the same command. For a device that should stay attached, run the attach in a retry loop or a systemd unit (see the docs). Not supported: hubs, audio/webcams (isochronous), more than one computer at a time.
